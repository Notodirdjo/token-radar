How implied value is computed

One function scores every protocol. The multiple is the category's median market-cap-to-TVL ratio among live-token protocols in this same snapshot; categories with fewer than 3 live comps use the global median instead. No protocol name is special-cased.

Method: the board ranks protocols that record no token, by an implied value built from their own TVL, seven-day growth and age, priced at their category's live-token multiple.
